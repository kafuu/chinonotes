# 1. 计算机网络概述
## 1.1. 计算机网络基本概念
### 1.1.1. 计算机网络的定义
- 计算机网络（网络）：**结点**（**node**）和连接结点的**链路**（**link**）组成计算机网络
- 互连网：通过**路由器**，把多个计算机网络连接起来，形成互连网
- 互联网：覆盖全球的互连网，形成互联网

通信设备：集线器（Hub，工作在第二层物理层）、交换机（Switch，工作在第三层数据链路层）、路由器（Router，工作在第四层网络层）
家用路由器 = 路由器 + 交换机 + 其他功能

互联网必须使用TCP/IP协议通信，互连网可以使用任意协议通信

ISP：互联网服务提供商

### 1.1.2. 计算机网络的组成与功能（理解）
（一）计算机网络的组成
①从**组成部分**看：计算机网络=硬件+软件+协议
- **硬件**
  - **主机**（端系统）：内部安装**网络适配器（网卡）**，实现通信协议
  - **通信设备**：如集线器，交换机，路由器
  - **通信链路**：网线、光纤……
- **软件**
- **协议**：由硬件和软件共同实现

②从**工作方式**看
- **边缘部分**：直接为用户服务，由主机和主机上的软件组成
- **核心部分**：为边缘部分提供**连通性和交换性服务**，由大量网络和连接网络的路由器组成
![alt text](image-2.png)

③从**逻辑功能**看
- **资源子网**：为用户提供资源，由主句组成
- **通信子网**：负责信息传输的部分，由通信链路+通信设备+协议构成
![alt text](image-1.png)
注：主机内部的**网络适配器、底层协议**属于**通信子网**的范畴

![alt text](image-3.png)

（二）计算机网络的功能
- **数据通信**：最基本，最重要的功能
- 资源共享：硬件、软件、数据资源共享
- 分布式处理：复杂的任务分派给其他计算机，如矩阵运算
- 提高可靠性：各台计算机互为互补替代机，提高可靠型，如云网盘
- 负载均衡：多台计算机分担繁重的任务，如游戏服务器

### 1.1.3. 三种数据交换技术
- **电路交换**：通过**物理线路**的连接，**动态**地分配传输线路资源，用于**电话网络**
  - 过程：建立连接（尝试占用通信资源） - 通信（一直占用通信资源） - 释放连接（归还通信资源  
  - 优点：独占专用物理通路，通信过程始终占用，**传输速率高**
  - 缺点：需要建立释放连接，需要额外的**时间开销**；线路被独占，**利用率低**；线路分配的**灵活性差**；不支持**差错控制**（无法发现数据错误）
  - 适用于：**低频次，大量传输数据**
- **报文交换**：报文包括**控制信息**+**用户数据**，控制信息指明发送方接受方，用于**电报网络**
  - 过程：**存储转发**
  - 优点：通信前**无需建立连接**；报文存储转发，**灵活分配线路**；用**户不独占**物理线路，利用率高；支持**差错控制**
  - 缺点：**报文不定长**，不方便存储转发管理；长报文的**时间开销和缓存开销大**；长报文容易出错，**重传代价高**
- **分组交换**：解决报文不定长的问题，长报文切分为定长的若干分组，用于**现代网络**
  - **分组**(**Packet**)的结构：**首部**（**Header**）（原地址，目的地址，**分组号**） + 数据
  - 优点：无连接，分组存储转发，不独占，差错控制
  - 相比报文交换，分组定长方便存储转发；分组转发时间开销小，缓存开销小；分组不易出错，重传代价低
  - 缺点：**控制信息增加**；相比电路交换，存在存储转发**时延**；分组可能**失序、丢失**
- 虚电路交换：基于分组交换，会先建立连接

### 1.1.5. 计算机网络的分类
（一）按分布范围分类
- **广域网**（WAN）：跨省/国/洲
- 城域网（MAN）：采用**以太网技术**，城市
- **局域网**（LAN）：采用**以太网技术**，企业学校家庭
- 个域网（PAN）：也常称为无线个域网，采用无线技术

（二）按传输技术分类
- 广播式网络：广播范围内计算机都会收到数据包，通过检查目的地址决定是否接受
- 点对点网络：点对点发送给接收方

注：无线网络都是广播式的，路由器转发是点对点

（三）按拓扑结构分类
- **总线型结构**：**广播式传输**，存在**总线争用**问题，如**集线器**连接设备
![alt text](image-10.png)
- **环形结构**：**广播式传输**，通过**令牌**解决总线争用问题，如**令牌环网**
![alt text](image-11.png)
- **星型结构**：由**中央设备**实现**点对点传输**，不存在总线争用问题，如**以太网交换机**，常见与局域网
![alt text](image-12.png)
- **网状结构**：点到点传输，如**路由器构建的广域网**

（四）按使用者分类
- 公用网：对公众开放
- 专用网：组织内部的网络

- 有线网络
- 无线网络

### 1.1.6. 计算机网络的性能指标

1. **速率**（数据率、比特率、数据传输速率）：节点在信道上传输数据的速率，单位为bit/s|b/s|bps，注意1Bps=8bps。1k=10^3，1M=10^6，与操作系统、计组不同……
2. **带宽**：信道的**最高传输率**
3. **吞吐量**：单位时间内通过的**实际数据量**（**包含上行和下行**）
4. 另一种含义的带宽：允许通过的信号频率范围（香农定理）,单位Hz
5. ※**时延、延迟、迟延**（Delay）：数据（一个报文或分组）从网络的一段传送到另一端所需的时间
   - $总时延 = 发送时延（传输时延） + 传播时延 + 处理时延 + 排队时延$
   - $发送时延=\frac{数据长度(bit)}{发送速率(bit/s)}$
   - $传播时延=\frac{信道长度(m)}{电磁波传播速度(m/s)}$
   - 排队时延、处理时延由诸多因素影响
6. **时延带宽积**：$时延带宽积=时延*数据传输率$，表示信道内残存的数据量，时延带宽积用于设计**最短帧长**
7. **往返时延（RTT）**：$往返时延=2*传播时延+发送方传输时延+处理时间$发送方发送完数据，到发送方接收到接收方发来的确认需要的时间，如游戏时延![alt text](image-17.png)
8. **信道利用率**：$信道利用率=\frac{有数据通过的时间}{总时间}$，信道利用率不能太低（浪费），也不能太高（容易拥堵）

注：
信道（Channel）：向某一方向信息传送的通道，一条通信信道在逻辑上往往对应一条**发送信道和接收信道**

【例】假设主机 A和B之间的链路带宽为 100Mbps，主机A的网卡速率为 1Gbps，主机B的网卡速率为 10Mbps，主机A给主机B发送数据的最高理论速率为(B)。
A. 1Mbps 
B. 10Mbps
C.100Mbps
D. 1Gbps

【例】H1给H2发送一个数据分组。分组大小=1000B，H1往链路A发送数据的速率为100Mbps，路由器往链路B发送数据的速率为80Mbps。链路A传播时延为0.01ms链路B传播时延为 0.05ms。不考虑路由器的处理时延、排队时延，求传输整个分组的总时延

【解】注意有**两个传输时延**，$传输时延1=1000B/1000Mbps=8*10^-5=0.08ms$ ，$传输时延2=1000B/80Mbps=8000b/80*10^6Mbps=10^-4s=0.1ms$，总时延=0.08+0.1+0.01+0.05=0.24ms

## 1.2. 计算机网络体系结构
### 1.2.1. 计算机网络分层结构
三种常见的网络体系结构：OSI参考模型、TCP/IP模型、教学用五层模型

**网络的体系结构**(Network Architecture)是计算机网络的**各层及其协议**的集合，就是这个计算机网络及其构件所应完成的**功能的精确定义**(**不涉及实现**)。
体系结构是**抽象**的，而实现是具体的

**实体**：第n层的活动元素（软件+硬件）称为第n层实体
**对等层**：不同机器上的相同层称为对等层
**对等实体**：不同机器上的同一层的实体称为对等实体
**协议**：控制**对等实体**之间进行通信的规则的集合，是**水平**的
**接口**：**相邻两层的实体**交换信息的逻辑接口，又称为**服务访问点**（SAP）
**服务**：**下层为紧邻的上层**提供功能调用，它是**垂直**的

**协议数据单元**（PDU）：**对等层次**之间传输的数据单位，由服务数据单元（SDU）和协议控制信息（PCI）组成，第n层的PDU记为**n-PDU**
**服务数据单元**（SDU）：**高一层次**传来的需要打包的信息
**协议控制信息**（PCI）：**本层添加**的打包协议信息
※$n-PDU=n-SDU+n-PCI=(n-1)-SDU$

协议的三要素：语法、语义、同步
**语法**：数据与控制信息的**格式**
**语义**：操作
**同步（时序）**：操作的条件，时序关系等

### 1.2.2. OSI参考模型
OSI参考模型从高到低：
- 7.**应用层**
- 6.**表示层**
- 5.**会话层**
- 4.**传输层**
- 3.**网络层**
- 2.**数据链路层**
- 1.**物理层**

常见的网络设备的功能层次（了解）
主机：1~7层
集线器：只实现物理层
交换机：实现物理层、数据链路层
路由器：实现物理层、数据链路层、网络层
各层通过物理传输媒体通信
![alt text](image-20.png)

各层的功能（了解）：
- 1.**物理层**：定义接口参数、传输信号的含义、电器特征
- 2.**数据链路层**（链路层）：
  - 保障逻辑上无差错，因此需要**差错控制**（检错+纠错+重传），使用校验编码技术；
  - **流量控制**功能（以**帧**为单位，只能保证**局部正确**）
- 3.**网络层**：传输单位为**数据报/分组**（Packet）
  - **路由选择**（选择最佳路径）；
  - **分组转发**；
  - 拥塞控制（发现并缓解拥塞）；
  - 网际互连（异构网络互连）；
  - 差错控制（与数据链路层不同的是，都是以**分组**为单位，保证了整组正确）、流量控制、连接建立与释放（确保有序）、可靠传输管理（需返回分组确认消息）等
  - 可向上层提供**有连接可靠的服务**（虚电路）和**无连接不可靠的服务**（数据报）
- 4.**传输层**：实现**端到端**的通信（每个端绑定一个进程），传输单位为**报文段**（Segment）
  - 传输层复用：发送方多个端口通过传输层
  - 传输层分用：接收方将接收的数据分发给不同端口
  - 差错控制（同理，以**报文段**为单位）、流量控制、连接建立与释放、可靠传输管理
  - **只能向上层提供有连接可靠的服务**
- 5.会话层
  - 会话管理：采用检查点机制，可恢复链接
- 6.表示层
  - 解决信息表示不一致（如编码格式不同，压缩格式不同）
- 7.应用层
  - 功能繁多，根据应用需求设计（如http协议）

各层的传输单位：
||单位|
|---|---|
|7.应用层|报文Message|
|4.传输层|报文段Segment|
|3.网络层|分组/数据报Packet|
|2.数据链路层|帧Frame|
|1.物理层|比特bit|

向下的过程称为数据的**分段**，向上的过程称为数据的**重装**

### 1.2.3. TCP/IP模型
TCP/IP模型从高到低：
- 4.**应用层**
- 3.**传输层**
- 2.**网络层**
- 1.**网络接口层**

TCP/IP模型与OSI参考模型的区别：
1. 并不是所有网络应用都需要表示层和会话层，因此将表示层和会话层的功能交给应用层的特定协议去实现
2. 网络接口的任务是为网络层传输Packet，但具体怎么传输不规定，提高灵活性和适应性
3. 网络层**去除**差错控制、流量控制、连接建立与释放、可靠传输管理的功能，提供的是**无连接不可靠的服务**（Segment）
4. 传输层进行复用和分用、差错控制、流量控制、连接建立与释放、可靠传输管理（把Segment拼接后检查），可提供**有连接可靠的服务**（**TCP协议**）和**无连接不可靠的服务**（**UDP协议**）

![alt text](image-23.png)

||OSI|TCP/IP|
|---|---|---|
|传输层|**有连接可靠的服务**|**有连接可靠的服务**（**TCP协议**）和**无连接不可靠的服务**（**UDP协议**）|
|网络层|**有连接可靠的服务**（虚电路）和**无连接不可靠的服务**（数据报）|**无连接不可靠的服务**（数据报）|
