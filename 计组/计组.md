### 1.1.2. 各个硬件的原理
（一）**主存储器的基本组成**
**存储体** + **MAR**（**存储地址寄存器**） + **MDR**（**存储数据寄存器**）

存储器由一个个**存储单元**组成，每个单元存放一串二进制代码
存储代码中二进制代码的组合称为**存储字**（word）
**存储字长**：存储单位中二进制位数，通常是8bit的整数倍
**存储元**：存储二进制的**电子元件**，存储1bit

**MAR的位数**决定了并等于存储单元的个数
**MDR的位数**：位数等于存储单元的位数，也就是字长，如果字长为16bit，MDR也是16位

注意区分：字，字节。字节（Byte/B）固定为8bit，字的大小不固定
![alt text](image-4.png)

（二）**运算器的基本组成**
**运算器**：实现算数运算、逻辑运算

运算器包括：
- ACC:累加器，用于存放操作数，或运算结果。
- MQ:乘商寄存器，在乘、除运算时，用于存放操作数或运算结果。
- X:通用的操作数寄存器，用于存放操作数
- **ALU**:算术逻辑单元，通过内部复杂的电路实现算数运算、逻辑运算

（三）**控制器的基本组成**
控制器包括：
- **CU**:控制单元，分析指令，给出控制信号
- IR:指令寄存器，存放当前执行的指令
- PC:程序计数器，存放下一条指令地址，有自动加1功能

**执行指令的具体过程**：

完成一条指令：取址（PC+IR） - 执行（CU）
1. 取指令：PC
2. 分析指令：IR
3. 执行指令：CU

计算机的工作过程：机器码保存在主存中
**第一条取数指令**（将内存中的数取入CPU寄存器）
1.  起始状态(PC)=0，指向第一条指令的存储地址，(PC)→MAR，则(MAR)=0
2.  查找
3. M(MAR)→MDR，第一条指令寄存到MDR
4. （MDR）→IR，指令送入指令寄存器
5. OP(IR)→CU，IR中的操作数（前面几位）送入CU，CU分析得知指令类型是取数
6. Ad(IR)→MAR，MAR=指令参数地址（地址码）
7. 查找
8. M(MAR)→MDR，找到参数值a
9. (MDR)→ACC（累加寄存器），ACC=a
![alt text](image-7.png)

**第二条乘法指令**：
第一条指令执行结束，PC自动+1，(PC=1)
1.  (PC)→MAR，则(MAR)=1
2.  查找
3. M(MAR)→MDR，指令寄存到MDR
4. （MDR）→IR，指令送入指令寄存器
5. OP(IR)→CU，IR中的操作数（前面几位）送入CU，CU分析得知指令类型是乘法
6. Ad(IR)→MAR，MAR=指令参数地址（地址码）
7. 查找
8. M(MAR)→MDR，找到参数值b
9. **(MDR)→MQ（乘商寄存器）**
10. **(ACC)→X，ACC=ab**，
11. **CU控制ALU执行乘法操作，(MQ)*(X)→ACC，如果乘积太大，需要MQ辅助存储**
![alt text](c67c17a5-ed7f-412e-879e-d583e99ab776.png)

**第三条加法指令**：
PC自动+1，(PC=2)
1.  (PC)→MAR，则(MAR)=2
2.  查找
3. M(MAR)→MDR，指令寄存到MDR
4. （MDR）→IR，指令送入指令寄存器
5. OP(IR)→CU，IR中的操作数（前面几位）送入CU，CU分析得知指令类型是加法
6. Ad(IR)→MAR，MAR=指令参数地址（地址码）
7. 查找
8. M(MAR)→MDR，找到参数值c
9.  **(MDR)→X**
10. CU控制ALU执行加法操作 **(ACC)+(X)=(ACC),ACC=ab+c**

**第四条存数指令**：
PC自动+1，(PC=3)
1.  (PC)→MAR，则(MAR)=3
2.  查找
3. M(MAR)→MDR，指令寄存到MDR
4. （MDR）→IR，指令送入指令寄存器
5. OP(IR)→CU，IR中的操作数（前面几位）送入CU，CU分析得知指令类型是存数
6. Ad(IR)→MAR，MAR=指令参数地址（地址码）
7. **(ACC)→MDR，MDR=ab+c**
8. **CU通过控制总线控制MDR中的数据放入MAR的地址中**

## 1.2. 计算机的性能指标：
（一）存储器
**存储器容量** = **MAR位数 * MDR位数**

（二）CPU
- **CPU主频**
- **CPU的时钟周期 = $\frac{1}{CPU主频}$**
- **CPI**：执行一条指令平均需要多少时钟周期
- **IPS**：每秒执行多少指令，**IPS = $\frac{主频}{CPI}$**
- **FLOPS**：每秒执行多少次浮点数运算

（三）系统整体
- **数据通路带宽**：数据总线的传送信息宽度
- **吞吐量**：系统单位时间内处理请求的数目
- **响应时间**：从发出请求到做出响应的等待时间

动态测试：使用**基准程序**测量计算机处理速度

### ※定点数的表示

**定点数**：小数点的位置固定
**浮点数**：小数点的位置不固定，使用科学计数法

**定点数的表示**：
- **定点整数**
  - **无符号整数**：无符号位，表示范围为$0到2^n-1$
  - **有符号整数**
    - **原码**：**最高位是符号位，0代表正数，1代表负数**，其余n-1位是数值的绝对值。n位原码表示范围为$[-(2^{(n-1)} - 1), 2^{(n-1)} - 1]$。映射方式：$0 → 2^{n-1}-1 → 0 → -2^{n-1}-1$ 
      - **问题**：**0的表示不唯一**；加减法运算复杂，需要根据符号位判断是加法还是减法
    - **反码**：正数与原码相同，负数的符号位为1，其余位置在原码基础上**逐位取反**。反码的表示范围为$[-(2^{(n-1)} - 1), 2^{(n-1)} - 1]$。映射方式：$0 → 2^{n-1}-1 → -2^{n-1}-1 → 0$ 
      - **问题**：**0的表示不唯一**；解决了减法问题（可以用加法实现），但会产生**循环进位**问题
    - **补码**：等于其**反码在末位加1**。表示范围为$-2^{n-1}到2^{n-1}-1$。循环方式：$0 → 2^{n-1}-1 → -2^{n-1} → -1$ 
    - **移码**：等于**补码的首位取反（相当于加$2^{n-1}$）**。表示范围为$-2^{n-1}到2^{n-1}-1$。循环方式：$-2^{n-1} → -1 → 0 → 2^{n-1}-1$
