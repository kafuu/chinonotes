**在计算机系统中，软件和硬件在逻辑上是等效的**（硬件能实现的，软件也能实现）

- 指令由**操作码和地址码组**成
- **以运算器为中心**（输入输出设备与存储器之间的**数据交换由运算器完成**）
控制器收到存储器的指令，控制所有部件

### 1.1.2. 各个硬件的原理
（一）**主存储器的基本组成**
**存储体** + **MAR**（**存储地址寄存器**） + **MDR**（**存储数据寄存器**）

存储器由一个个**存储单元**组成，每个单元存放一串二进制代码
存储代码中二进制代码的组合称为**存储字**（word）
**存储字长**：存储单位中二进制位数，通常是8bit的整数倍
**存储元**：存储二进制的**电子元件**，存储1bit

**MAR的位数**决定了并等于存储单元的个数
**MDR的位数**：位数等于存储单元的位数，也就是字长，如果字长为16bit，MDR也是16位

注意区分：字，字节。字节（Byte/B）固定为8bit，字的大小不固定
![alt text](image-4.png)

（二）**运算器的基本组成**
**运算器**：实现算数运算、逻辑运算

运算器包括：
- ACC:累加器，用于存放操作数，或运算结果。
- MQ:乘商寄存器，在乘、除运算时，用于存放操作数或运算结果。
- X:通用的操作数寄存器，用于存放操作数
- **ALU**:算术逻辑单元，通过内部复杂的电路实现算数运算、逻辑运算

（三）**控制器的基本组成**
控制器包括：
- **CU**:控制单元，分析指令，给出控制信号
- IR:指令寄存器，存放当前执行的指令
- PC:程序计数器，存放下一条指令地址，有自动加1功能

**执行指令的具体过程**：

完成一条指令：取址（PC+IR） - 执行（CU）
1. 取指令：PC
2. 分析指令：IR
3. 执行指令：CU

2.  查找

4. （MDR）→IR，指令送入指令寄存器
5. OP(IR)→CU，IR中的操作数（前面几位）送入CU，CU分析得知指令类型是加法

### 2.1.2. ※定点数的表示

**定点数**：小数点的位置固定
**浮点数**：小数点的位置不固定，使用科学计数法

**定点数的表示**：
- **定点整数**
  - **无符号整数**：无符号位，表示范围为$0到2^n-1$
  - **有符号整数**
    - **原码**：**最高位是符号位，0代表正数，1代表负数**，其余n-1位是数值的绝对值。n位原码表示范围为$[-(2^{(n-1)} - 1), 2^{(n-1)} - 1]$。映射方式：$0 → 2^{n-1}-1 → 0 → -2^{n-1}-1$ 
      - **问题**：**0的表示不唯一**；加减法运算复杂，需要根据符号位判断是加法还是减法
    - **反码**：正数与原码相同，负数的符号位为1，其余位置在原码基础上**逐位取反**。反码的表示范围为$[-(2^{(n-1)} - 1), 2^{(n-1)} - 1]$。映射方式：$0 → 2^{n-1}-1 → -2^{n-1}-1 → 0$ 
      - **问题**：**0的表示不唯一**；解决了减法问题（可以用加法实现），但会产生**循环进位**问题
    - **补码**：等于其**反码在末位加1**。表示范围为$-2^{n-1}到2^{n-1}-1$。循环方式：$0 → 2^{n-1}-1 → -2^{n-1} → -1$ 
    - **移码**：等于**补码的首位取反（相当于加$2^{n-1}$）**。表示范围为$-2^{n-1}到2^{n-1}-1$。循环方式：$-2^{n-1} → -1 → 0 → 2^{n-1}-1$ 
      - **优点**：**方便对比大小**

移码的偏置值：**偏置值+十进制真值=移码值**

### 2.1.3. C语言的定点整数强制转换

### 2.2.1. 加法器
（一）**一位加法器**
**一位全加器（FA）**
$S_i=A_i\oplus B_i\oplus C_{i-1}$
$C_i=A_iB_i+(A_i\oplus B_i)C_{i-1}$

（二）**并行加法器**
**串行进位加法器**
![alt text](image-18.png)
**缺点**：进位信息串行产生，计算速度取决于进位速度，**位数越多，运算速度越慢**
特点：**串行进位的并行加法器**（并行指支持允许并行输入）  
注：串行进位又叫**行波进位**

**并行进位加法器**：进位信息**并行产生**，**几乎没有延迟**

（三）**带标志位的加法器**
1. 溢出：**OF标志位**，判断**带符号加减**是否溢出。**CF标志位**，判断**无符号数**是否溢出
2. 运算结果是否为0：**ZF标志位**，判断加减操作是否为0
3. 结果为正还是负：**SF标志位**，判断**带符号加减结果正负**

标志位实现：
**OF**：$C_n\oplus C_{n-1}$
**SF**：$S_n$
**ZF**：$\overline{S_n+S_{n-1}...+S_1}$
**CF**：$C_n\oplus C_0$

### 2.2.3. 定点数的移位运算
移位运算：左移k位，等于乘以n^k

定点数的移位运算：
- **逻辑移位**：适用与**无符号整数**
- **算数移位**：适用于**带符号整数**

（一）**逻辑移位**
- **逻辑左移**：高位移出丢弃，低位补0。如果左移丢弃的位=1，会导致**溢出**
- **逻辑右移**：低位移出丢弃，高位补0。如果右移丢弃的位=1，会导致**丢失精度**

（二）**算数移位**
- **算数左移**：高位移出丢弃，低位补0。如果**符号位发生改变**，会导致溢出
- **算数右移**：低位移出丢弃，高位**补符号位**。如果右移丢弃的位=1，会导致丢失精度

### 2.2.4. 定点数的加减运算
（一）原码的加减（了解）：分为正正，负负，正负。减法：转换为加法。正正负负需要考虑到溢出

（二）**补码的加减**：加法直接加，减法取相反数（取反+1）相加

- **溢出**：正数加正数可能正溢，负数可能负溢
- 判断溢出方法：
  - **符号位发生改变**（$A_SB_S\overline{S_S}+\overline{A_S}·\overline{B_S}{S_S}=1$
  - **根据符号位的进位和数值位的进位情况**：如果符号位和数值位同时进位：0000 - 1111没有溢出。只有当**符号位和数值位不同时进位**，才会发生溢出：$C_S\oplus C_1=1$。下溢：符号位进位为1。上溢：数值位进位为1。
  - **采用双符号位法**：正数符号位为00，负数符号位为11，计算结果符号位为01，发生上溢，符号位为10，发生负溢。$S_{S1}\oplus S_{S2}=1$

双符号位补码：**模四补码**。单符号位补码：**模二补码**
双符号位存储时只会保存一个，计算时复制一个符号位

### 2.3.1. 无符号整数的乘法原理
方法：逐位相乘（移位），得到部分积，**叠加**得到乘积结果

![alt text](image-27.png)

※**硬件实现**：关键词：**加法，移位，循环**
硬件：**乘积寄存器P和乘数寄存器Y组成2n位**，被乘数寄存器X为n位
1. 开始时，被乘数，乘数放入寄存器中，乘积寄存器置为0，控制逻辑计数器置为n
2. 控制逻辑检查被乘数和乘数是否全零，如果全0则结果为0
3. 重复n轮移位，加法运算：
   1. 最低位送入控制逻辑
   2. 控制逻辑进行判断，如果最低位为1，**执行加法P+X，运算结果写回P**，进位放入单独的一位**进位触发器C**中;如果最低位为0，什么也不做
   3. 控制逻辑发出右移信号，**CPY整体右移一位**
   4. **控制逻辑计数器$C_n$减一**

处理方法：1.忽略；2.处理溢出异常：执行乘法指令后执行一条**溢出自陷指令**，指令会**检查OF标志位**，如果溢出就执行**异常处理程序**

与带符号整数的乘法，电路不同：

区别：
1. 乘数寄存器低位新增一位**辅助位**
2. 控制逻辑一次取两个bit（辅助位+乘数末位）
3. 不保存最高位的进位信息

※**硬件实现**：关键词：**取两位，加或减**
硬件：**乘积寄存器P，乘数寄存器Y和辅助位组成2n+1位**，被乘数寄存器X为n位
1. 开始时，被乘数，乘数放入寄存器中，乘积寄存器置为0，控制逻辑计数器置为n

3. 重复n轮移位，**加减运算**：

   2. 控制逻辑进行判断，如果最低位为**01**，执行**加法P+X**，运算结果写回P，如果最低位为**10**，执行**减法P-X**，运算结果写回P，如果最低位为**00或11**，不操作![alt text](image-31.png)

   4. **控制逻辑计数器$C_n$减一**

溢出判断：**取前n+1位**（例如4位*4位，取结果的前5位）如果前n+1位**都为0或都为1**，则**没有溢出**，如果**不完全相同**，则**溢出**

### 2.3.4. 无符号整数的除法运算原理
（一）手算方法：
二进制上商规则：**中间余数大于等于除数，上商1，否则上商0**
![alt text](image-37.png)

（二）除法电路的基本结构，基本原理，**重点关注：开始状态，结束状态，除法异常判断**

![alt text](image-38.png)
**支持2n bit除以n bit，得到n bit商和n bit余数**

※**硬件实现**：
硬件结构：除数寄存器Y，余数寄存器R与余数/商寄存器Q，组成2n bit，控制逻辑控制ALU的加减和RQ的左移和写使能
1. 开始
   1. 将数据放入寄存器：**除数放入Y；被除数放入RQ，完成零扩展；Cn置为n**
   2. 检查特殊情况：
      1. **除数0判断**：如果除数为0，发生“除数为0”异常，停止除法运算，调出操作系统的异常处理程序
      2. **商0判断**：被除数的绝对值小于除数的绝对值，直接**商0，余数等于被除数**，不必除法
2. 运算过程，进行**n+1轮**处理：上商规则与手算相同，**中间余数大于等于除数，上商1，否则上商0**
   1. 第一轮**特殊处理**：
      1. 直接上商，如果第一位商1，发生“**商溢出**”异常，停止除法运算
      2. 如果第一位商0，无事发生（这一位**不会保存**，**Cn也不会--**）
   2. 后n轮循环处理
      1. 左移，RQ最低位空出用于保存商
      2. 上商，同样按照上商规则，背后可能进行加法/减法
      3. 计数器Cn--，Cn=0时除法运算结束
3. 结果：
   1. R：**最终的余数**，Q：**最终的商**
      

注意**恢复余数法**：试减的时候中间余数会先减除数，如果错减就**再加上除数**，所以控制逻辑需要控制ALU进行加运算和减运算

（三）除法异常：除数为0，商溢出

关于除法商溢出：
  - 该除法器支持：双精度除法，单精度除法
  - 2n bit/n bit称为**双精度除法**，可能发生商溢出；
  - n bit/n bit称为**单精度除法**，**不可能发生商溢出**

## 2.4. 浮点数的表示和运算
### 2.4.1. ※浮点数的表示：IEEE 754
float：32bit；double：64 bit
（一）科学计数法
科学计数法：**符号+尾数*基数^阶码**， $\plusmn尾数*基数^{阶码}$
![alt text](image-40.png)
**规格化**：尾数的**最高非0数位**刚好在小数点前
尾数决定了**浮点数的精度**，阶码决定了**浮点数的表示范围**

（二）**IEEE 754浮点数的存储格式**：单精度/双精度
保存二进制的浮点数，需要保存：**符号位、阶码、尾数**，阶数固定为2

- float型：**1bit符号位+8bit阶码位+23bit尾数位**
- double型：**1bit符号位+11bit阶码位+52bit尾数位**
- long double型：80位扩展精度浮点型；16bit半精度浮点型；128bit四倍精度浮点型

1. **float单精度型**：
   - 符号位：0正1负
   - 尾数：默认存储规格化的浮点数，**小数点前的1省略**（1.尾数）
   - 阶码：用**移码**表示，偏置为**127**
     - **E全0为-127**，当尾数为0时代表无穷小（0），尾数不为0时代表是非规格化数，隐含的整数位为0
     - **E全1为128**，当尾数为0时代表无穷大，尾数不为0代表NaN
     - **E=1000 0000为1**
1. **double双精度型**：
   - 符号位：0正1负
   - 尾数：默认存储规格化的浮点数，小数点前的1省略（1.尾数）
   - 阶码：用移码表示，偏置为**1023**
     - **E全0为-1023**，当尾数为0时代表无穷小（0），尾数不为0时代表是非规格化数，隐含的整数位为0
     - **E全1为1024**，当尾数为0时代表无穷大，尾数不为0代表NaN
     - **E=100 0000 0000为1**


（三）题型：**真值转浮点数；浮点数转真值**

**真值 → 浮点**

例1：-8.25转换为float型：
解：符号位为1，1000.01科学计数法表示为1.00001*2^3，尾数为0000100 00000000 00000000，阶码真值为3，移码为1000 0010。浮点数为1100 0001 0000 0100 0000 0000 0000 0000 = C104 0000（HEX）

**浮点 → 真值**

例2：C640 0000H转换为真值：
解：1 10001100 10000000000 0000 0000 0000，符号为负，阶码为1100+1=1101=13，尾数为0.5，因此为$-1.5*2^{13}$

### 2.4.2. ※IEEE 754浮点数的表示范围，特殊状态
（一）**规格化浮点数**表示范围
**阶码不全为0，也不全为1，表示这是一个规格化的浮点数**
阶码全为0或全为1用于特殊解读

**表示范围**：
1. 阶码的表示范围为(1~254)-127 = -126~127
2. 最小绝对值为0 0000 0001 0000……=$1.0*2^{-126}$
3. 最大的绝对值为0 1111 1110 1111……=$1.1111……*2^{127}$ = $(2-2^{-23})*2^{127}$
4. 不在范围内的，被表示为0或无穷
![alt text](image-43.png)

（二）**超出规格化的表示范围的解决方法**

①**上溢的处理**：
**正上溢**：运算结果大于最大规格化正数
**负上溢**：运算结果小于最小的规格化负数
正上溢与负上溢统称为上溢（Overflow）/溢出
**溢出的处理方法**：运算结果设为$+\infin或者-\infin$（0/1 11111111 0000……）
默认不响应浮点数溢出异常，不中断程序，可手动开启

②**下溢的处理**：
  1. 落入非规格化区间，用**非规格化浮点数**存储
  2. 若下溢至机器零，运算结果设为**正0或负0**(1/0 00000000 0000……)
  3. 设置浮点数下溢异常标志位（如x86的FPU的UE标志位），默认不响应浮点数下溢异常，不中断程序，可手动开启
  ![alt text](image-44.png)

**注**：非规格化浮点数：0/1 00000000 f（非0），表示$0.f*2^{-126}$，
**非规格化浮点数绝对值最小为$2^{-149}$**(0/1 00000000 000……0001)
**非规格化浮点数绝对值最大为$2^{-126} - 2^{-149}$**
$0/1 00000000 1111…1111 = 0.1111……1111(23个1)*2^{-126} = (1 - 2^{-23}) × 2^{-126} = 2^{-126} - 2^{-149})$

例题：float类型8020 0000H的值为
解答：1 00000000 01000000000000000000000，是一个非规格化浮点数，$-0.25*2^{-126}=-2^{-128}$

# 3. 存储系统
## 3.1. 存储系统概览
（一）存储器的层次化结构：
**寄存器 - Cache（高速缓冲存储器） - 主存（内存） - 辅存（硬盘） - 外存（磁带，光盘等）**
从前到后：**速度越来越慢，容量越来越小，造价越来越低**
![alt text](image-48.png)

**存储器的调入调出关系图**：![alt text](image-49.png)
（**CPU，Cache，主存**互相读写，由硬件自动完成，**主存与辅存**相互读写,由操作系统与硬件负责（页面置换算法））

Cache-主存的作用：**缓解CPU与主存之间的速度矛盾**
主存-辅存的作用：**实现虚拟存储系统，解决主存容量不够的问题**

（二）存储器的分类：

（1）按存储介质分类
- **半导体存储器**：主存，Cache
- **磁表面存储器**：磁盘，磁带
- **光存储器**：光盘

（2）按存取方式分类
- **随机存取存储器（RAM）**：读写任一单元**时间都相同**，与物理位置无关
- **顺序存取存储器（SAM）**：读写一个存储单元的时间**取决于物理位置**
- **直接存取存储器（DAM）**：既有随机存取的特性，又有顺序存取的特性
- **相联存储器（CAM）**：**按照内容**检索到存储为止进行读写，如**快表**

SAM与DAM统称**串行访问存储器**

（3）按信息的可更改性
- **读写存储器**：磁盘，内存，Cache
- **只读存储器（ROM）**：如光盘

（4）按信息的可保存性
- **易失性存储器**（主存，Cache）：断电后信息消失
- **非易失性存储器**（磁盘，光盘）
- **破坏性读出**（如DRAM芯片）
- **非破坏性读出**（如SRAM、磁盘、光盘）

（三）存储器的性能指标：
**存储容量**：存储字长 * 字长
**单位成本**：每位价格 = 总成本 / 总容量
**存储速度**：**数据传输率** = 数据宽度（**存储字长**）/存储周期  

注：
1. 存储字长 = MDR的位数
2. **存取时间**：启动存取到完成一次存取所需要的时间，分为读出时间和写入时间
3. **存取周期**：两次独立存取之间的最小时间，包括存取时间和恢复时间
4. **主存带宽**又称为数据传输率，也就是存储速度
